# Task Management Application

A full-stack Task Management application featuring user authentication, strict data isolation, real-time dashboard statistics, profile management, and comprehensive task CRUD operations.

---

## Technologies Used

### Backend
* **Node.js** & **Express** (TypeScript)
* **Prisma ORM** with **PostgreSQL**
* **Zod** (Input validation)
* **JWT** (JSON Web Tokens for authentication)
* **bcrypt** (Password hashing)
* **Resend** (Email service for password resets)

### Frontend
* **React** (TypeScript) with **Vite**
* **Tailwind CSS** (Styling)
* **Axios** (HTTP Client)
* **React Router DOM** (Client-side routing)

---

## Requirements & Prerequisites

Ensure you have the following installed on your machine:
* **Node.js** (v18.x or higher)
* **npm** or **yarn**
* **PostgreSQL** (Running locally or via a cloud instance like Neon/Supabase)
